# DELTAPAW

*A mod about a cat* — небольшая игра про кота по имени **Полночь** (Polnoch), сделанная на движке [Kristal](https://github.com/KristalTeam/Kristal) в стиле DELTARUNE.

Тихий дом, утро, прогулка с хозяином по городу и парку, странные сны и загадочный незнакомец.

## Скачать

Последняя версия — на странице [Releases](../../releases). Скачай архив `DeltaPaw-v1.0.zip`.

## Как установить и запустить

DELTAPAW — это мод, поэтому для игры нужен сам движок Kristal.

1. Скачай **Kristal v0.9.0** (или новее) со страницы релизов движка: https://github.com/KristalTeam/Kristal/releases
2. Распакуй и запусти Kristal один раз, затем закрой его.
3. Открой папку модов Kristal: на Windows это `%APPDATA%\kristal\mods` (вставь этот путь в адресную строку Проводника). Если папки `mods` там нет — создай её.
4. Распакуй из архива папку `deltapaw` прямо в папку `mods`, чтобы получилось `mods/deltapaw/mod.json`.
5. Запусти Kristal и выбери **DELTAPAW** в списке модов.

## Управление

| Клавиша | Действие |
|---|---|
| Стрелки | ходьба |
| Z / Enter | подтвердить, взаимодействовать |
| X / Shift | отмена, бег (зажать) |
| C / Ctrl | меню |

## Что внутри

- 17 локаций: дом, город, парк, дорога в лес и тёмный лес
- 14 сюжетных сцен и финальные титры
- 3 боя во снах и наяву, 10 видов атак
- Жители города, с которыми можно поговорить
- Собственный саундтрек
